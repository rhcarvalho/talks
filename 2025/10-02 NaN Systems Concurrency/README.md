## Abstract

My goal with this presentation is to instigate curiosity and foster learning by
exploring different mechanisms for achieving concurrency and parallelism in
programming languages.

In a way, it also reflects the "main language" transitions in my career, in
particular the shift from Python to Go, and now Elixir.

I've always been keen on learning new programming languages and paradigms, as it
broadens one's perspective and understanding of different approaches to problem
solving. Concurrency itself is a non-trivial concept, and concurrent code is
often the source of great confusion, complexity and headaches.

By understanding that there's no one-size-fits-all solution, we can better
appreciate the trade-offs involved in different approaches to concurrency (and
programming language design) and how it affects the systems we build.
